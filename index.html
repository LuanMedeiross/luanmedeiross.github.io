Stored XSS High

Cross-site scripting persistente em campo de perfil de usuário. Payload executado no contexto de outros usuários autenticados, permitindo roubo de sessão e ações arbitrárias.

SQL Injection Critical

Injeção SQL em endpoint de busca sem sanitização de input. Exploração manual permitiu extração de dados sensíveis do banco e enumeração da estrutura interna.

Bug Bounty — Plataforma SaaS ler →
CSRF Medium

Cross-site request forgery em ação de troca de e-mail sem validação de token. Possibilidade de sequestro de conta via link malicioso enviado ao alvo.

Bug Bounty — App Web ler →
IDOR High

Insecure Direct Object Reference em endpoint de documentos. Alteração de parâmetro de ID permitia acesso a arquivos de outros usuários sem validação de autorização.
